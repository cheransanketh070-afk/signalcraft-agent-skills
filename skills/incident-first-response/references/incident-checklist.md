# Incident checklist

## First 15 minutes
- [ ] Record detection time and timezone
- [ ] Notify incident owner / on-call lead
- [ ] Identify affected service, account, environment, and potential impact
- [ ] Choose a safe containment action; get approval where required
- [ ] Preserve relevant logs and state before rotation/cleanup where feasible
- [ ] Avoid sharing secrets or personal data outside authorized channels

## First hour
- [ ] Create a time-ordered incident timeline
- [ ] Confirm scope and likely entry point without overclaiming
- [ ] Review access logs, identity events, deploys, config changes, and alerts
- [ ] Rotate or revoke credentials through approved procedures if indicated
- [ ] Assess customer/data impact with security/privacy/legal owners
- [ ] Draft an accurate internal update and set the next update time
- [ ] Record every action, approver, timestamp, and outcome

## Recovery and follow-up
- [ ] Root cause mitigated or contained
- [ ] Recovery source validated as trusted
- [ ] Integrity and user journeys checked
- [ ] Enhanced monitoring in place
- [ ] External notifications assessed by qualified owners
- [ ] Post-incident review scheduled
- [ ] Corrective actions have owners and due dates
