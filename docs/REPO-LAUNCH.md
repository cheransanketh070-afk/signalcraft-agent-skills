## Launch post draft

I built **SignalCraft** — an open set of 13 practical skills for AI agents.

Not another collection of “act like an expert” prompts. Each skill is a repeatable workflow with clear steps, useful templates, safety boundaries, and a way to verify the result.

Included workflows for: 
- evidence-first research and current-source checks
- debugging broken repos and reviewing code for security risks
- evaluating AI features before calling them “good”
- reliable automation, release readiness, and incident first response
- launch messaging, content repurposing, and customer discovery
- decision briefs, data stories, and truthful CV tailoring

The same skills are packaged for compatible ChatGPT/Codex and Claude workflows. The repo includes install scripts, individual Claude upload ZIPs, a validator, and GitHub Actions checks.

I’m sharing it early to get practical feedback: **Which workflow would you add, remove, or improve first?**
