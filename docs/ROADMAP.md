# Roadmap

The focus is usefulness and verifiability, not maximizing the number of directories.

## Potential next steps

- Add small, reproducible evaluation fixtures for selected skills and document their limitations.
- Offer localized interview, CV, and customer-research templates.
- Add optional platform-specific metadata only where it materially improves discovery.
- Collect issue reports on false triggers, missing steps, and confusing output contracts.

## Acceptance bar for new skills

A proposed skill should solve a distinct repeatable job, define clear inputs and outputs, include safety boundaries, remain concise, and have at least one positive and one negative activation test.
